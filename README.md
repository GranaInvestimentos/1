# Grana — publicação no GitHub Pages

Este pacote contém o site completo, com os arquivos de publicação na raiz.

1. Crie um repositório público chamado `grana` na sua conta do GitHub.
2. Extraia este ZIP e envie o conteúdo, mantendo a pasta `fonts` e colocando `index.html` na raiz.
3. Abra Settings → Pages → Build and deployment.
4. Selecione Deploy from a branch, branch `main` e pasta `/ (root)`, depois Save.
5. Aguarde o GitHub mostrar a URL publicada.

Na conta agriam336-del, o endereço será https://agriam336-del.github.io/grana/.
O endereço https://grana.github.io/ exige controle da conta/organização grana e um repositório chamado grana.github.io.

Sem backend de aplicação ou dependências de instalação. O site usa HTML, CSS e JavaScript.

Não inclua o PDF da pesquisa: o site já contém somente contagens agregadas.
